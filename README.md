## Local setup

Prerequisites: Git, Conda and Python 3.12.

```bash
git clone https://github.com/vishwajeet0304/python-for-data-science.git
cd python-for-data-science
conda create -n aiml python=3.12
conda activate aiml
python -m pip install numpy pandas matplotlib seaborn scikit-learn jupyter ipykernel
```

If the aiml environment already exists, skip the environment creation command.
